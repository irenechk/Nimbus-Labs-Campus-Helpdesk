# Part F2 — Reflection

Skills, Plugins, MCP, and Git Worktrees solved different problems in this project. The timetable Skill provided the agent with focused instructions, examples, reference material, and a helper script. It helped the agent interpret timetable questions, ask for missing details, and avoid inventing schedule entries. The Plugin packaged the Skills and security hook so they could be installed and managed together through Antigravity. MCP provided a structured interface to mock campus data: two named tools for timetable and fee lookups, plus a hostel-rules resource. Git Worktrees allowed separate branches and working directories for Skill tests, MCP development, and hook-path work without repeatedly switching the main working directory.

I would choose a Skill over an MCP tool when the main requirement is guidance: explaining a workflow, applying domain-specific instructions, handling ambiguity, or progressively loading reference material. I would choose an MCP tool when the agent needs a clearly defined operation with a predictable input and output schema, such as retrieving a batch timetable or a mock fee status. The two approaches can work together: a Skill can guide the conversation and decide when an MCP tool is appropriate.

I would not let an agent independently approve security-sensitive changes, manage credentials, deploy production software, delete important data, or resolve consequential merge conflicts without human review. This project demonstrated why verification matters. The protected-folder live test initially succeeded when it should have been blocked, revealing a gap between a simulated hook test and actual agent behaviour. The package lookup also returned an npm 404, and MCP Inspector initially failed because `uv` was missing. These incidents show that plausible explanations and successful syntax checks are not enough. I would inspect actual tool calls, test both allowed and denied cases, verify packages against their registries, review diffs, and preserve logs before accepting an agent's claims.
