# Nimbus Labs Campus Helpdesk Agent

## Project Overview
This project develops and audits an AI-agent toolchain for a fictional campus helpdesk at Nimbus Labs.

The agent is designed to answer student queries using mock timetable and fee information, along with campus hostel rules.

## Project Components
1. **AI Skill:** Timetable Helper for answering timetable-related queries.
2. **Plugin:** Campus Helpdesk plugin that packages the Skill and related tools.
3. **MCP Server:** Provides timetable, fee-status and hostel-rules information.
4. **Git Worktrees:** Supports parallel development of different project components.

## Data and Security
- Only fictional mock student data will be used.
- No real student records, passwords or API keys will be included.
- Responses must not invent timetable entries or fee information.
- Tool errors and uncertain information must be reported clearly.
