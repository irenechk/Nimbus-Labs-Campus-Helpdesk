
# Timetable CSV Dictionary

## Overview

The timetable.csv file contains fictional campus timetable records.

Each row represents one scheduled class.

## Column Definitions

| Column | Description | Example |
|---|---|---|
| batch | Student batch identifier | A |
| day | Scheduled weekday | Monday |
| start_time | Class starting time | 09:00 |
| end_time | Class ending time | 10:00 |
| subject | Subject name | Data Structures |
| faculty | Assigned faculty member | Prof Sharma |
| room | Assigned classroom | Room 101 |

## Data Rules

1. Batch identifiers are stored as letters.
2. Day names are stored in full.
3. Time values use 24-hour HH:MM format.
4. Each row represents one class.
5. Only records present in the CSV are valid timetable information.
6. All records are fictional and created for this assignment.
